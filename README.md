# Aplicação DevOps

## Descrição
Aplicação Node.js utilizando Express que serve uma página HTML e disponibiliza um endpoint com os integrantes do grupo.

## Tecnologias utilizadas
- Node.js
- Express

## Como executar

1. Instale as dependências:
npm install

2. Execute o projeto:
node src/index.js

3. Acesse no navegador:
http://localhost:3000  
http://localhost:3000/integrantes

## Estrutura do projeto

src/
 ├── index.js
 └── views/
     └── index.html
